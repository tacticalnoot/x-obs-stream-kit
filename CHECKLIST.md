# Pre-Stream Checklist

Run through this every time before going live.

---

## Before Streaming

- [ ] X account is **public** (not protected posts)
- [ ] Internet connection is stable (Ethernet > Wi-Fi)
- [ ] Cloud backups / large downloads paused
- [ ] Game is launched and running

## OBS Checks

- [ ] Scene: **DRAGONWILDS** is selected
- [ ] **Game Capture** shows the game (not black)
- [ ] **Desktop Blurred** is below Game Capture in source order
- [ ] Audio Mixer: game audio meter **moving**
- [ ] Audio Mixer: **no mic meter** visible
- [ ] Audio Mixer: **no desktop audio meter** visible

## Settings Verified

- [ ] Output: CBR, **9000 Kbps**, Keyframe **3 sec**
- [ ] Video: **1280×720**, **60 FPS**
- [ ] Audio: **AAC 128 Kbps**
- [ ] Stream: **Custom** service, RTMP URL + key entered

## Go Live

- [ ] OBS: **Start Streaming** (green light in bottom bar)
- [ ] X Producer: **Start Broadcast**
- [ ] Verify on phone (cell data): video ✅ game audio ✅ no mic ✅

## After Stream

- [ ] X Producer: **Stop Broadcast**
- [ ] OBS: **Stop Streaming**
- [ ] Check that replay/VOD posted to your profile
